**Язык программирования:** Python

### Полное определение КС-грамматики (LL(1))
```text
E  -> TA
A  -> ε | + TA | - TA
T  -> FB
B  -> ε | * FB | / FB | // FB | % FB | ** FB
F  -> num | id | (E)
id -> letter {letter | digit | _}
num -> digit {digit}
```

### Примеры верных строк (выражений)
* `10 + 20 * 3`
* `a + b * 2`
* `a + b - c * d / e % f`
* `100 // (10 + 5) * 2`

## 1. Лексический и синтаксический анализ

### Описание
Лексер читает исходный текст посимвольно и разбивает его на токены: числа (`num`), идентификаторы (`id`), операторы (`op`) и скобки (`paren`). Пробельные символы игнорируются. Если встречается недопустимый символ, генерируется токен ошибки.

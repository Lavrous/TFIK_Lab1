## Вариант задания

**Тема работы:** Построение абстрактного синтаксического дерева (AST) для объявления функции с параметрами, указанием типов и математическим выражением в операторе возврата. Интеграция семантических проверок поверх готового синтаксического парсера.

**Пример верных строк кода:**
```python
def calc(a: int, b: int, c: int) -> int:
    return a + (b * c);
```
```python
def mult(x: int, y: int) -> int:
    return x * y;
```

---

## Контекстно-зависимые условия (Семантические правила)

В программе реализована таблица символов и проверка двух контекстно-зависимых условий:

1. **Правило 1: Уникальность идентификаторов (параметров).**  
   Проверяется, что имя параметра не было объявлено ранее в сигнатуре функции.  
   * **Пример ошибки:** `def calc(a: int, a: int) -> int:`
   * **Ожидаемое сообщение:** `Повторное объявление идентификатора 'a'`

2. **Правило 2: Использование объявленных идентификаторов.**  
   Проверяется, что переменные, используемые внутри математического выражения, были предварительно объявлены в качестве параметров.  
   * **Пример ошибки:** `return a + x;` (где `x` не было в параметрах)
   * **Ожидаемое сообщение:** `Использование необъявленной переменной 'x'`

## Структура AST

### Описание типов узлов
В программе спроектирована следующая иерархия узлов:

* `FunctionDeclNode` — Корень дерева, обозначает объявление функции (хранит имя функции).
* `ArgNode` — Узел, группирующий список параметров функции.
* `IntNode` — Узел целочисленной переменной. Хранит имя переменной.
* `ReturnTypeNode` — Узел возвращаемого типа функции (хранит имя типа, например, `int`).
* `statement sequence` — Узел последовательности инструкций (тело функции).
* `ReturnNode` — Узел оператора `return`.
* `BinOpNode` — Узел бинарной математической операции (хранит оператор `+` или `*`).

### Формат вывода AST в программе
Если лексический, синтаксический и семантический анализы прошли без ошибок, программа автоматически генерирует текстовый файл `AST.txt` в корневой директории и открывает его в текстовом редакторе по умолчанию. 

Дерево выводится в читаемом псевдографическом формате с отступами:
```text
FunctionDeclNode
├── def: calc
├── ArgNode
│   ├── IntNode
│   │   └── name: a
│   ├── IntNode
│   │   └── name: b
│   └── IntNode
│       └── name: c
├── statement sequence
│   └── ReturnNode
│       └── BinOpNode
│           ├── op: +
│           ├── IntNode
│           │   └── name: a
│           └── BinOpNode
│               ├── op: *
│               ├── IntNode
│               │   └── name: b
│               └── IntNode
│                   └── name: c
└── ReturnTypeNode
    └── name: int
```

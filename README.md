# TFIK_Lab1: Разработка GUI для языкового процессора

**Лабораторная работа №1**  
Дисциплина: Теория формальных языков и компиляторов (ТФЯиК)

---

## Описание проекта
Специализированный текстовый редактор с кроссплатформенным графическим интерфейсом (GUI). Проект представляет собой основу для будущего языкового процессора.

На текущем этапе реализован полноценный пользовательский интерфейс с меню, панелью инструментов и текстовыми областями.

## Инструкция по установке и запуску

Сборка проекта не требуется. Программа упакована в исполняемый файл.

1. Перейдите в папку `dist`.
2. Запустите файл `Lab1.exe` двойным щелчком мыши.

Допустимо отдельное скачивание Lab1.exe и запуск на "чистой" системе (без предустановленной IDE и библиотек).

## Руководство пользователя

### Меню "Файл"
| Функция | Описание |
|:---|:---|
| **Создать** | Создает новый пустой текстовый файл. |
| **Открыть** | Открывает диалоговое окно для выбора и загрузки существующего файла. |
| **Сохранить** | Сохраняет текущие изменения в открытом файле. |
| **Сохранить как** | Позволяет сохранить текущий текст в новый файл под другим именем. |
| **Выход** | Закрывает программу (с предупреждением). |

### Меню "Правка" и Горячие клавиши
Реализованы стандартные функции редактирования текста:

| Функция | Горячие клавиши | Описание |
|:---|:---:|:---|
| **Отменить** | `Ctrl` + `Z` | Отменяет последнее действие. |
| **Повторить** | `Ctrl` + `Y` | Повторяет ранее отмененное действие. |
| **Вырезать** | `Ctrl` + `X` | Удаляет выделенный текст и помещает его в буфер обмена. |
| **Копировать** | `Ctrl` + `C` | Копирует выделенный текст в буфер обмена. |
| **Вставить** | `Ctrl` + `V` | Вставляет текст из буфера обмена. |
| **Удалить** | `Ctrl` + `D` | Удаляет выделенный текст без сохранения в буфер. |
| **Выделить всё** | `Ctrl` + `A` | Выделяет весь текст в активном поле. |

### Меню "Справка"
*   **Справка:** Вызывает окно с описанием функций меню "Файл" и "Правка".
*   **О программе:** Вызывает окно с информацией о разработчике и версии ПО.

## Текущий статус разработки
**На данный момент** основная логика языкового процессора находится в разработке.  
При запуске обработки текста программа работает в режиме **"заглушки"**: текст просто переносится из входного поля в выходное без изменений.  
**Сохранение** на данный момент реализовано как сохранение текста во входном поле в качестве текстового файла на диск. По мере развития проекта, при необходимости, механизм сохранения может быть переработан.

# TFIK_Lab1
1. Название и цель лабораторной работы: Лабораторная работа 1. Разработка пользовательского интерфейса (GUI) для языкового процессора
2. Сведения об авторе: Коваленко Евгений Алексеевич, студент АП-327
3. Описание проекта: Специализированный текстовый редактор с кросплатформенным графическим интерфейсом (GUI)
4. Используемые технологии: Python, PySide6 для создания GUI, PyCharm в качестве IDE, PyInstaller для "запаковки" проекта в исполняемый файл
5. Инструкция по сборке и запуску: Сборка не требуется, достаточно запустить (двойным нажатием) файл Lab1.exe. Он находится в папке dist.
6. Описание интерфейса и функций (руководство пользователя):
Меню "Файл": 
  Создать: Создает новый пустой текстовый файл. 
  Открыть: Открывает существующий файл в редакторе. 
  Сохранить: Сохраняет текущие изменения в открытом файле. 
  Сохранить как: Позволяет сохранить текущий текст в новый файл. 
  Выход: Закрывает программу с предупреждением. 
Меню "Правка": 
  Отменить (Ctrl+Z): Отменяет последнее действие в активном поле. 
  Повторить (Ctrl+Y): Повторяет отмененное действие. 
  Вырезать (Ctrl+X): Удаляет выделенный текст и помещает его в буфер обмена. 
  Копировать (Ctrl+C): Помещает выделенный текст в буфер обмена. 
  Вставить (Ctrl+V): Вставляет текст из буфера обмена. 
  Удалить (Ctrl+D): Удаляет выделенный текст без сохранения в буфер. 
  Выделить всё (Ctrl+A): Выделяет весь текст в активном поле.
Меню "Справка":
  Справка: Вызывает описание реализованных функций для меню "Файл" и "Правка
  О программе: Вызывает краткое описание программы
В Toolbar реализованы иконки функций создания файла, открытия файла, сохранения файла, отмены последнего действия, восстановления отмененного действия, вырезания,
копирования и вставки, вызова справки и информации о программе.
8. На данный момент при запуске программы она ничего не делает, а просто переносит текст с одного текстового поля в другое. Это заглушка.

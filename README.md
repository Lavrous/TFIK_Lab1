## Описание проекта

Лексический анализатор (сканер) для выделения лексем из входного текста, интегрированный в графический интерфейс языкового процессора из лабораторной работы №1.

Сканер последовательно читает текст символ за символом и выделяет лексемы в соответствии с грамматикой подмножества языка Python — объявлений функций. Результаты анализа отображаются в табличном виде с указанием типа, значения и позиции каждой лексемы.

## Вариант задания

**Вариант 79.** Создание функции на языке Python.

Объявление функции в Python начинается с ключевого слова `def`, после которого указывается имя функции и аргументы в круглых скобках. Блок кода выделяется отступами (4 пробела по стандарту PEP8, но технически достаточно и одного). Для возврата значения используется ключевое слово `return`. Тип возвращаемого значения указывается через оператор `->`.

Примеры корректных входных данных:

```python
def calc(a: int, b: int, c: int) -> int:
    return a + (b * c);
```

```python
def big(x: int, y: int, z: int) -> int:
    return x * y * z;

def simple(x: int):
    return x;
```

## Диаграмма состояний

![Image](https://github.com/user-attachments/assets/475a243e-da08-40c9-95fd-9271b7cb6b9c)

Аппарат последовательно читает текст символ за символом, перемещаясь между состояниями в зависимости от встреченного символа.

| Состояние | Описание |
|:---|:---|
| **0 — Начальное** | Определяет тип следующей лексемы по первому символу. Буква → состояние 1, пробел → состояние 2, дефис → состояние 3. Одиночные разделители распознаются мгновенно, автомат остаётся в состоянии 0. |
| **1 — Слово** | Накапливает буквы. При встрече не-буквы проверяет буфер: если `def`, `int` или `return` — выдаёт код ключевого слова, иначе — код идентификатора. |
| **3 — Стрелка** | После символа `-` ожидает строго `>`. Если пришёл `>` — фиксируется оператор `->`. Любой другой символ — ошибка. |
| **ERROR** | Фиксирует координаты недопустимого символа и продолжает разбор. |
| **;** | Принудительно закрывает последнюю активную лексему и выдаёт финальный маркер завершения. |
